# ModelForge 实现路径规划

## 1. 实施原则

### 1.1 优先级策略

1. **核心功能优先**: Excel 财务建模工具优先 (P0)。
2. **高频功能优先**: 快捷键、跨应用联动、Deck Check 等。
3. **可独立运行**: 每个模块可独立测试和发布。
4. **平滑升级**: 兼容已有代码，便于后续扩展。

### 1.2 开发模式

- 阶段式开发，每个阶段交付可用功能。
- 单元测试覆盖关键功能。
- 持续集成确保代码质量。

## 2. 技术路线

### 2.1 架构设计：VSTO + Office JS API 混合架构 + 后端桥接

#### 2.1.1 架构选型理由

| 能力需求                                        | Web Add-in  | VSTO          | 结论                     |
| ----------------------------------------------- | ----------- | ------------- | ------------------------ |
| Keyboard Shortcuts (快捷键)                     | ❌ 不支持   | ✅ 完全支持   | **P0级刚需，必须用VSTO** |
| Link Excel to PowerPoint/Word (深度COM引用绑定) | ❌ 能力有限 | ✅ 完全支持   | 需要VSTO实现             |
| 颜色板、共享库检索                              | ✅ 轻量更新 | ❌ 需重新安装 | Web更灵活                |
| Deck Check 报告生成界面                         | ✅ 热更新   | ❌ 需重新安装 | Web更优                  |
| Ribbon 菜单融合                                 | ✅ 支持     | ✅ 支持       | 两者皆可                 |

**重要澄清**：VSTO 与 Web Add-in 运行在不同进程，无法直接通信。两者之间的功能协调必须通过**后端 API 桥接** (ASP.NET Core) 实现。

### 2.2 开发实施风险与对策

| 风险                              | 影响 | 缓解措施                                                |
| --------------------------------- | ---- | ------------------------------------------------------- |
| VSTO 与 Web Add-in 无法直接通信   | 高   | 强制使用后端 API 桥接，制定统一接口规范                 |
| Office 版本兼容性 (2016/2019/365) | 中   | 多版本测试，版本检测 + 功能降级                         |
| .NET 运行时依赖                   | 中   | 打包自包含运行时，或要求用户安装 .NET 8 Desktop Runtime |
| 快捷键冲突                        | 低   | 提供冲突检测 UI，允许用户自定义                         |

## 6. 风险与应对

| 风险类别              | 具体描述                         | 缓解策略                                         |
| --------------------- | -------------------------------- | ------------------------------------------------ |
| **Office 版本兼容性** | 不同版本 Office COM 接口行为差异 | 覆盖 Office 2016/2019/365 测试，关键功能回退方案 |
| **VSTO 部署权限**     | 用户可能无管理员权限安装         | 提供 ClickOnce 或 MSI 支持用户级安装             |
| **快捷键冲突**        | 与其他全局热键软件冲突           | 内置冲突检测 + 提醒用户自定义                    |
| **跨应用链接稳定性**  | Excel 与 PPT 链接断裂难以追踪    | 增加链接健康状态检查，自动修复向导               |
| **AI 数据安全**       | 客户不允许将内容发送至公有 LLM   | 提供私有化部署选项 (Llama3)，支持 BYOK           |
| **后端桥接性能**      | 高频调用 API 可能延迟            | 关键路径使用本地缓存，批量操作合并请求           |
