# ModelForge 实现路径规划

## 1. 实施原则

### 1.1 优先级策略

1. **核心功能优先**: Excel 财务建模工具优先
2. **高频功能优先**: 使用频率高的功能优先开发
3. **可独立运行**: 每个模块可独立测试和发布
4. **平滑升级**: 兼容已有代码，便于后续扩展

### 1.2 开发模式

- 阶段式开发，每个阶段交付可用功能
- 单元测试覆盖关键功能
- 持续集成确保代码质量

---

## 2. 技术路线

### 2.1 架构设计：VSTO + Office JS API 混合架构 (Hybrid 模式)

#### 2.1.1 架构选型理由

| 能力需求                                        | Web Add-in  | VSTO          | 结论                     |
| ----------------------------------------------- | ----------- | ------------- | ------------------------ |
| Keyboard Shortcuts (快捷键)                     | ❌ 不支持   | ✅ 完全支持   | **P0级刚需，必须用VSTO** |
| Link Excel to PowerPoint/Word (深度COM引用绑定) | ❌ 能力有限 | ✅ 完全支持   | 需要VSTO实现             |
| 颜色板、共享库检索                              | ✅ 轻量更新 | ❌ 需重新安装 | Web更灵活                |
| Deck Check 报告生成界面                         | ✅ 热更新   | ❌ 需重新安装 | Web更优                  |
| Ribbon 菜单融合                                 | ✅ 支持     | ✅ 支持       | 两者皆可                 |

#### 2.1.2 技术分工

```
┌─────────────────────────────────────────────────────────────────┐
│                        Ribbon 功能区 (融合)                       │
├─────────────────────────────┬───────────────────────────────────┤
│      VSTO Commands           │       Web Add-in Commands         │
│   (压力级速度建模)            │    (灵活更新无需安装包)            │
├─────────────────────────────┴───────────────────────────────────┤
│                                                                   │
│   VSTO 负责：                    Web Add-in 负责：                 │
│   ├── 快捷键系统                 ├── 合同与品牌库运维后台           │
│   ├── 跨应用数据联动              ├── Dashboard 统计               │
│   ├── 公式追踪                   ├── Omnibar 速查栏                │
│   ├── 文件优化                   ├── AIWA 前端 UI                 │
│   ├── 模型检查                   └── 管理员后台配置台             │
│   └── 形状批量操作                                             │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

#### 2.1.3 技术栈

| 层级              | 技术选型                              | 说明                |
| ----------------- | ------------------------------------- | ------------------- |
| **VSTO 运行时**   | .NET Framework 4.8+ / .NET 8          | 桌面插件宿主        |
| **Office JS API** | Office.js + Office Add-in Manifest    | Web 插件            |
| **通信桥接**      | SharedRuntime (VSTO + Web 共享运行时) | Ribbon 融合         |
| **前端框架**      | React 18 / TypeScript                 | Web Add-in UI       |
| **状态管理**      | Zustand / Redux Toolkit               | Web Add-in 状态     |
| **UI 组件库**     | Fluent UI React                       | Microsoft 设计系统  |
| **构建工具**      | Vite + Webpack                        | Web Add-in 打包     |
| **后端 API**      | RESTful / GraphQL                     | Web Add-in 数据接口 |

#### 2.1.4 项目结构建议

```
ModelForge/
├── src/
│   ├── vsto/                        # VSTO 插件项目
│   │   ├── ModelForge.AddIn/        # Excel VSTO
│   │   ├── ModelForge.PowerPoint/   # PowerPoint VSTO
│   │   └── ModelForge.Word/         # Word VSTO
│   │
│   ├── web/                         # Web Add-in 项目
│   │   ├── packages/
│   │   │   ├── office-ui-fabric-react/
│   │   │   └── @microsoft/office-js/
│   │   ├── src/
│   │   │   ├── components/          # React 组件
│   │   │   ├── views/               # 页面视图
│   │   │   ├── services/            # API 服务
│   │   │   └── hooks/               # 自定义 Hooks
│   │   ├── package.json
│   │   └── vite.config.ts
│   │
│   └── shared/                      # 共享代码
│       ├── constants/               # 常量定义
│       ├── types/                   # 类型声明
│       └── utils/                   # 工具函数
│
├── docs/                            # 文档
├── manifest/                        # Add-in Manifest 配置
└── README.md
```
