# ModelForge 0.1.3 发布说明

发布日期：2026-06-07  
发布类型：内测 / 试点候选版

## 1. 发布摘要

`0.1.3` 是 Sidecar + Backend + Web Add-in 混合架构的试点候选版。当前版本已覆盖 Excel 建模效率工具、PowerPoint/Word 基础 COM 能力、Backend 管理 API、Corporate Dictionary、39 个已实现命令快捷键配置、MSI 可复现构建和 Office 2024 用户式命令级 E2E。

## 2. 主要新增

- Sidecar API 信封化：`/api/execute`、`/api/status`、快捷键导入/导出均返回结构化 `ApiEnvelope<T>`。
- Sidecar 本地 API 令牌：可选配置 `Sidecar:LocalApiToken` 保护 `/api/*`，Web task pane 与 Ribbon function-file 可携带 `X-ModelForge-Sidecar-Token`。
- Admin 用户与角色路径：登录、用户列表、新增、启停、内置角色权限只读矩阵、重复/非法输入错误信封和 E2E 覆盖。
- Admin 诊断与统计：`/api/admin/diagnostics` 输出安全的发布排障摘要，`/api/admin/diagnostics/bundle` 下载安全 JSON 诊断包；`/api/admin/audit-events/summary` 输出最近审计事件类型/用户/宿主 Top 10、时间趋势和事件类型 × 宿主热力图；`/api/admin/audit-events/retention` 支持审计保留策略预览/清理；Web Admin Console 已提供“诊断”、审计摘要、趋势、热力图和保留策略面板。
- Web UI 点击审计：导航、命令执行、快捷键配置、Deck Check、链接刷新、Admin、词典和 AIWA 显式用户操作会 best-effort 上报 `ui.*` 审计事件；普通信息级事件受 `TelemetryEnabled` 控制。
- 隐私合规基础：`TelemetryEnabled=false` 默认关闭普通信息级使用统计；安全/认证/管理和 Warning+ 事件仍记录。
- Corporate Dictionary：术语管理、命中高亮、JSON/CSV/XLSX 模板导入导出；配置服务令牌后 Deck Check 可自动读取 Backend 企业词典。
- PowerPoint：形状对齐/分布/统一尺寸完整矩阵、Deck Check Logo 位置和品牌化 HTML/PDF 报告基础版。
- Cross-app Linking：Excel→PowerPoint OLE 链接修复，`excel.refresh-links` 接入后端 LinkMetadata 驱动精准刷新基础版。
- Web Add-in：Excel/PPT/Word `FunctionFile` 静态回归，Ribbon 命令映射到 Sidecar host。
- 部署：MSI/WiX 可复现构建，Backend/Sidecar 支持 Windows Service 生命周期。

## 4. 安装与试点

1. 使用管理员 PowerShell 运行安装回归：`.\scripts\test-msi-admin.ps1`；如需手动安装，先执行 `$msi = (Resolve-Path ".\ModelForge.msi").Path`，再执行 `msiexec /i $msi /l*v "$PWD\install.log"`。
2. 验证服务：`sc query ModelForge.Sidecar`、`sc query ModelForge.Backend`。
3. 验证健康检查：`curl http://localhost:5200/health`、`curl http://localhost:5095/health`。
4. 按 `docs/Office-Add-in-企业分发指南.md` 侧载或集中部署 manifest。
5. 按 `docs/安全自查清单.md` 完成试点门禁确认。

## 5. 已知限制

- MSI 为 `perMachine` 安装包；发布验收必须使用管理员 PowerShell，并通过 `scripts/test-msi-admin.ps1` 或绝对 MSI 路径执行。当前管理员安装/卸载回归已通过；非管理员安装会因权限不足失败。
- Ribbon 真实点击回归仍需在 Excel/PowerPoint/Word 侧载后人工逐项验证。
- 生产 SSO、自定义 RBAC/用户组、租户策略和集中密钥下发仍未完成；Sidecar 本地令牌为试点基础版，默认空值保持开发兼容。
- 审计保留策略为基础清理能力；审计归档签名、防篡改链和长期留存证明仍未完成。
- LinkMetadata 驱动刷新为基础版，当前可按 `targetAddress` 精准定位 PowerPoint/Word 目标对象；目标地址不足或对象缺失时仍回退 Office OLE/字段全量扫描，失效链接自动修复待补。
- Deck Check 可通过 `forbiddenTerms` 参数检查术语；配置服务令牌后可自动读取 Backend Corporate Dictionary，未配置时保持本地默认术语回退。
- AIWA 仍为 Mock/试点链路，生产 LLM 接入和数据出境策略待完成。
- 100+ 快捷键对应命令规格、Deck Check 颜色规则/集中品牌模板管理和视频教程待补。

## 6. 回滚

- Add-in 集中部署：在 Microsoft 365 Integrated apps / Add-ins 管理页取消分配或移除应用。
- 本机安装：管理员 PowerShell 执行 `$msi = (Resolve-Path ".\ModelForge.msi").Path` 后运行 `msiexec /x $msi /l*v "$PWD\uninstall.log"`。
- 回滚后确认 Office Ribbon 消失，`ModelForge.Sidecar` / `ModelForge.Backend` 服务停止或不存在。
