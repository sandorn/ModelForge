# ModelForge 技术路线重新规划

## Context

**问题**: VS 2026 移除了 Office/SharePoint Development 工作负载，VSTO 正式被 Microsoft 淘汰。原基于 `.NET Framework 4.8 + VSTO` 的架构无法在新 IDE 中开发调试。

**目标**: 采用 2026 年最先进技术栈，重新设计架构，最大化重用现有 75% 代码资产。

**现有资产**: 40 个源文件中 30 个可完全重用或仅需微小改动。VSTO 层的 10 个文件需要完全重写。后端、Web、共享契约层零 VSTO 依赖。

**COM 互操作方案（规划）**: 原计划采用 **原生 COM** (MIT 许可)。**当前实现（2026-06）** 已改为 .NET 10 原生 COM：`oleaut32!GetActiveObject` P/Invoke + `dynamic` 延迟绑定 + `OfficeApplicationFactory` 显式释放（见 `docs/CHANGELOG.md`）。

## 新架构：Hybrid Sidecar Pattern

```
┌──────────────────────────────────────────────────────────────────────┐
│                     Microsoft Excel (Desktop)                         │
│                                                                       │
│  ┌──────────────────────────┐    ┌────────────────────────────────┐  │
│  │  Office Web Add-in        │    │  ModelForge.Sidecar             │  │
│  │  (React 18 + Fluent 9)   │    │  (.NET 10 Web Host (Minimal API))        │  │
│  │                           │    │                                 │  │
│  │  ├─ Ribbon (20+ 按钮)     │    │  ├─ REST API (:5200)           │  │
│  │  ├─ 任务窗格 UI           │◄───┤  ├─ 全局键盘钩子 (Win32)        │  │
│  │  ├─ 快捷键 (Office.js)    │    │  ├─ 原生 COM 引擎      │  │
│  │  └─ AIWA/Omnibar         │    │  ├─ Formula Tracer             │  │
│  └──────────┬───────────────┘    │  ├─ Model Check                │  │
│             │                     │  └─ Cross-App Linking           │  │
│             │ HTTP REST           └──────────────┬─────────────────┘  │
│             │                                     │                    │
└─────────────┼─────────────────────────────────────┼────────────────────┘
              │                                     │
              │          ┌──────────────────────────▼──────────────────┐
              │          │  ModelForge.Backend (.NET 10 ASP.NET Core)    │
              └──────────┤  • Admin Console  • Dictionary  • Audit     │
                         │  • Dashboard  • AIWA  • Config (:5095)     │
                         └─────────────────────────────────────────────┘
```

### 三层职责

| 层                    | 技术                                              | 职责                                                                            |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Office Web Add-in** | React 18 + Fluent UI 9 + Office.js                | Ribbon UI、任务窗格、快捷键(Office.actions)、Omnibar、AIWA 前端                 |
| **Sidecar**           | .NET 10 Web Host (Minimal API) + 原生 COM Interop | 全局键盘钩子(Win32)、COM深度操作(公式追踪/跨应用链接/ModelCheck)、本地 REST API |
| **Backend**           | ASP.NET Core 10 + InMemory / SQLite / PostgreSQL  | 企业配置、审计日志、术语字典、AI 编排、Dashboard 统计                           |

### 关键 ADR

| ADR         | 决策                                                                                                     |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| **ADR-001** | .NET 10 Sidecar REST 服务 + **原生 COM**（oleaut32!GetActiveObject P/Invoke + dynamic 延迟绑定，零 PIA） |
| **ADR-002** | Office Web Add-in 承载所有 Ribbon UI + 任务窗格，使用 manifest `ExecuteFunction` 定义按钮                |
| **ADR-003** | Sidecar 与 Web Add-in 通过 localhost REST (:5200) 通信，与后端通过 HTTP (:5095) 通信                     |
| **ADR-004** | 全线使用 .NET 10（Backend、Sidecar、Contracts、测试工程均为 `net10.0`）                                  |
| **ADR-005** | 数据库通过 Provider 抽象支持 InMemory / SQLite / PostgreSQL；Docker Compose 默认 PostgreSQL              |

## 实施阶段

### Phase A: Foundation (Week 1-2)

**A.1 创建 .NET 10 Sidecar Web Host 项目**

- 创建 `src/sidecar/ModelForge.Sidecar/` 项目 (`Microsoft.NET.Sdk.Worker`, `net10.0`)
- 创建命令与快捷键模块: `ExcelCommandIds.cs`, `ShortcutDefinition.cs`, `DefaultShortcutMap.cs`, `ShortcutRegistry.cs`, `SidecarOptions.cs`, `BackendBridgeClient.cs`
- 创建 `Interop/`: `OfficeApplicationFactory.cs` (原生 COM), `ExcelInteropService.cs`, `PowerPointInteropService.cs`, `WordInteropService.cs`
- 新增 `Keyboard/`: `GlobalKeyboardHook.cs` (WH_KEYBOARD_LL P/Invoke), `ChordParser.cs`, `KeyboardCommandRouter.cs`
- 新增 `Api/SidecarEndpoints.cs`: `GET /health`, `POST /execute`, `GET /shortcuts`
- 本地 REST API 端口: **5200**

**A.2 升级现有项目到 .NET 10**

- `src/backend/`: `net10.0`
- `src/shared/`: `net10.0`
- `tests/backend/`、`tests/sidecar/`、`tests/e2e/`: `net10.0`
- `.github/workflows/ci.yml`: 更新 dotnet-version, 添加 Sidecar 构建 job

**A.3 增强 Office.js Manifest**

- 添加 `FunctionFile` 引用
- 添加 20+ `ExecuteFunction` 按钮 (PowerTools, Audit, Linking, Workbook, Formatting groups)
- 新建 `src/web/src/function-file.ts` (Office.js 函数命令入口)
- 新建 `src/web/src/services/sidecarClient.ts` (Sidecar HTTP 客户端)

### Phase B: Power Tools & 核心功能 (Week 3-6)

**B.1 Power Tools 实现**: FillRight, FillDown, IfErrorWrapper, StatisticsInserter (COM 实操)

**B.2 键盘快捷键引擎**: 完整 WH_KEYBOARD_LL 钩子, ChordParser, KeyboardCommandRouter, 冲突检测

**B.3 Visualizations**: CellClassifier (硬编码/公式/外部链接三色标记), AuditColorMarker

**B.4 Model Check**: ErrorValueScanner, ExternalLinkScanner, CircularReferenceDetector, HardcodedValueScanner

**B.5 任务窗格通信**: sidecarClient 完整实现, bridgeStore 扩展, TaskPane 主布局

### Phase C: 高级功能 (Week 7-10)

**C.1 跨应用链接**: ExcelToPowerPointLinker, ExcelToWordLinker (OLE 链接), LinkRefresher

**C.2 公式追踪**: PrecedentTracer, DependentTracer (Range.DirectPrecedents/Dependents)

**C.3 Prepare to Share / Workbook Optimization**: 安全副本生成, 公式→值, 批注清除, 元数据抹除

**C.4 Web 层增强**: Dashboard, Omnibar (fuse.js), AIWA Chat, Dictionary Editor

### Phase D: 打磨部署 (Week 11-12)

**D.1 WiX MSI 安装器**: Sidecar (self-contained win-x64) + Backend + Web Add-in + 清单注册

**D.2 E2E 测试**: Playwright + xUnit, 测试样本: `samples/excel/model-with-errors.xlsx`

**D.3 文档更新**: `docs/architecture.md`, User Guide, Admin Guide, CHANGELOG

| ----------------- | ----------------------------------------------- | ------------------------------------- |

| Ribbon UI         | Office.js manifest `ExecuteFunction`            | Web Add-in 承载全部 Ribbon            |
| Ribbon 回调       | `src/web/src/function-file.ts`                  | TypeScript → Sidecar REST             |

## 风险与缓解

| 风险                                               | 缓解                                                                                           |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `GetActiveObject` 权限不匹配或 WPS/旧 COM 抢占 ROT | 异常处理 + 诊断日志 + Microsoft Office 版本/路径校验 + `scripts/check-office-runtime.ps1` 预检 |
| 全局键盘钩子触发杀毒软件                           | Code-sign Sidecar, 提供关闭选项                                                                |
| COM 内存泄漏 (长会话)                              | 显式 COM 释放 (FinalReleaseComObject) 层级释放，无需手动管理                                   |
| Office 2016/2019/365 兼容                          | 多版本测试矩阵, 功能降级检测                                                                   |
| Web Add-in 需要 HTTPS                              | Vite HTTPS 开发配置, 企业 CA 生产证书                                                          |
