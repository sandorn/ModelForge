# ModelForge 开发环境搭建（阶段一）

本文档说明阶段一工程骨架的本地开发、运行和验证方式。当前阶段包含 ASP.NET Core 后端桥接服务、React Web Add-in 任务窗格、Excel Sidecar 服务和 Office manifest。

## 1. 工具链要求

### 1.1 通用工具

| 工具 | 建议版本 | 用途 |
| --- | --- | --- |
| Git | 2.40+ | 版本管理。 |
| .NET SDK | 10.0.x | 构建 Sidecar、Backend、Contracts（`net10.0`）。CI 使用 `dotnet-version: 10.0.x`。 |
| Node.js | 20 LTS | 构建 Web Add-in。当前机器为 Node 24，可能存在依赖兼容差异，CI 使用 Node 20 固定验证。 |
| npm | 10+ | 安装前端依赖。 |
| Visual Studio Code | 最新版 | 日常编辑。 |

### 1.2 Sidecar 专用工具

Sidecar 采用 .NET 10 Web Host（Minimal API）+ 原生 COM Interop：

- .NET 10 SDK
- Microsoft Office 2016/2019/365 桌面版（用于 COM 互操作测试）
- Visual Studio 2022/2026 或 VS Code（仅需 C# 扩展）
- 无需 Office/SharePoint Development workload

仓库中包含 Sidecar 服务与 Web Add-in 前端，涵盖命令常量、快捷键映射、原生 COM 互操作层、键盘钩子、后端客户端和 REST API。

## 2. 仓库结构

```text
model-forge/

  manifest/                     Office Web Add-in manifest
  samples/                      样例文件说明与后续样例资产

```

## 3. 后端桥接服务

### 3.1 构建

```cmd
dotnet build src\backend\ModelForge.Backend\ModelForge.Backend.csproj
```

### 3.2 启动

```cmd
scripts\dev-backend.cmd
```

启动后默认监听：

```text
http://localhost:5095
```

### 3.3 验证接口

```cmd
curl http://localhost:5095/health
curl http://localhost:5095/api/version
curl http://localhost:5095/api/commands
```

### 3.4 烟测

```cmd
scripts\smoke-backend.cmd
```

烟测验证至少 20 个 Excel 高频命令，并检查关键命令入口是否存在。

## 4. Web Add-in 任务窗格

### 4.1 安装依赖

```cmd
cd src\web
npm install
```

> 注意：安装依赖会生成 `node_modules/` 和 `package-lock.json`。首次提交建议保留 `package-lock.json` 以保证 CI 可复现。

### 4.2 启动开发服务器

```cmd
scripts\dev-web.cmd
```

默认地址：

```text
http://localhost:5173
```

### 4.3 构建

```cmd
cd src\web
npm run build
```

### 4.4 后端地址配置

如需调整后端地址，可在 `src/web/.env.local` 中设置：

```env
VITE_MODELFORGE_API_URL=http://localhost:5095
```

## 5. Office Web Add-in 侧载

阶段一 manifest 位于：

```text
manifest/modelForge.web.xml
```

开发期默认任务窗格地址为 `http://localhost:5173`。部分 Office 版本对 Web Add-in 资源要求 HTTPS，如遇到侧载失败，可采用以下方案之一：

1. 使用 Office 官方开发证书和 HTTPS dev server。
2. 临时在受信任目录侧载 manifest，并仅用于本机开发验证。
3. 后续改造 Vite HTTPS 配置和本地证书自动化脚本。

manifest 中图标资源当前由 Web dev server 提供，路径为：

```text
/assets/icon-16.png
/assets/icon-32.png
/assets/icon-64.png
/assets/icon-80.png
```

## 6. Sidecar 开发流程

Sidecar 是 .NET 10 本地 REST 服务，通过 `oleaut32!GetActiveObject` 与 Office COM 互操作，通过 localhost REST 与 Web Add-in 通信。

项目位置：

```text
src/sidecar/ModelForge.Sidecar/
```

### 6.1 构建

```cmd
dotnet build src/sidecar/ModelForge.Sidecar/
```

### 6.2 启动

```cmd
scripts\dev-sidecar.cmd
```

启动后监听：

```text
http://localhost:5200
```

### 6.3 验证 Sidecar

```cmd
curl http://localhost:5200/health
curl http://localhost:5200/api/shortcuts
```

### 6.4 开发调试流程

1. 安装 .NET 10 SDK 和 Microsoft Office 桌面版 Excel。
2. 启动后端桥接服务：

   ```cmd
   scripts\dev-backend.cmd
   ```

3. 启动 Sidecar（开发模式，控制台运行）：

   ```cmd
   scripts\dev-sidecar.cmd
   ```

4. 启动 Web Add-in 开发服务器：

   ```cmd
   scripts\dev-web.cmd
   ```

5. 在 Excel 中侧载 Office Add-in manifest：

   ```text
   manifest\modelForge.web.xml
   ```

6. Excel 启动后应出现 `ModelForge` Ribbon 标签。
7. 点击 Ribbon 按钮验证 Sidecar `/execute` 接口。
8. 按键测试全局键盘钩子（如 `Ctrl+Alt+R` → FillRight）。

Sidecar 开发约束：

- Sidecar 使用 .NET 10 Minimal API + `IHostedService`（键盘钩子）。
- `OfficeApplicationFactory` 负责 COM 对象追踪与 `FinalReleaseComObject` 释放。
- Sidecar 与 Web Add-in 通过 localhost REST (:5200) 通信，与后端通过 HTTP (:5095) 通信。
- 任何 Office 自动化逻辑必须考虑异常恢复和 Excel 进程释放。
- 生产环境 Sidecar 以 Windows Service 模式运行。

## 8. 常见问题

### 8.1 Web 任务窗格无法连接后端

检查：

1. 是否已运行 `scripts\dev-backend.cmd`。
2. 后端是否监听 `http://localhost:5095`。
3. 浏览器开发者工具中是否存在 CORS 错误。
4. `VITE_MODELFORGE_API_URL` 是否配置为正确地址。

### 8.2 `dotnet build` 找不到 .NET SDK

请安装 .NET 10 SDK（10.0.x）。项目所有工程均目标 `net10.0`，不再支持 .NET 8/9 构建。

### 8.3 Office manifest 侧载失败

优先检查 HTTPS、图标 URL、`SourceLocation` 和 Office 受信任目录配置。阶段一 manifest 以本地开发验证为主，生产发布前需要完整签名和 HTTPS 托管。

## 9. 阶段一完成标准

- 后端 `/health`、`/api/version`、`/api/commands` 可访问。
- Web Add-in 任务窗格能显示后端健康状态、版本和命令数量。
- 命令目录至少包含 20 个 Excel 高频命令。
- Sidecar 工程包含 localhost REST API、原生 COM 互操作层、Win32 键盘钩子和后端桥接客户端。
- `scripts\smoke-backend.cmd` 能通过。
- CI 能在干净环境中执行后端、Web、Sidecar 构建。
