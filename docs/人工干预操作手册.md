## 1. SSO 集成 — Azure AD / Okta（P2.12）

### 前置条件

- Azure 租户管理员权限（或 Okta 管理员账号）
- ModelForge Backend 部署域名（如 `https://modelforge.yourcompany.com`）

### 方案 A：Azure AD（推荐用于 Microsoft 365 企业）

#### 步骤 1：注册应用

1. 登录 [Azure Portal](https://portal.azure.com) → **Microsoft Entra ID** → **应用注册** → **新注册**
2. 填写：
   - 名称：`ModelForge`
   - 支持的帐户类型：`仅此组织目录中的帐户`
   - 重定向 URI：`Web` → `https://modelforge.yourcompany.com/api/auth/callback`
3. 点击 **注册**

#### 步骤 2：配置客户端凭据

1. 进入应用 → **证书和密码** → **新建客户端密码**
2. 记录生成的 `ClientSecret`（只显示一次）
3. 进入 **概述**，记录 `Application (client) ID` 和 `Directory (tenant) ID`

#### 步骤 3：配置 API 权限

1. 进入 **API 权限** → **添加权限** → **Microsoft Graph**
2. 添加委托权限：
   - `User.Read`（登录和读取用户个人资料）
   - `User.Read.All`（读取组织用户列表）
   - `GroupMember.Read.All`（读取组成员资格）
3. 点击 **代表管理员授予同意**

#### 步骤 4：配置 ModelForge 环境变量

在 Backend 服务器的 `.env` 或环境变量中设置：

```bash
# Azure AD SSO
SSO__Enabled=true
SSO__Provider=azuread
SSO__AzureAd__TenantId=<Directory (tenant) ID>
SSO__AzureAd__ClientId=<Application (client) ID>
SSO__AzureAd__ClientSecret=<ClientSecret>
SSO__AzureAd__CallbackPath=/api/auth/callback
SSO__AzureAd__Authority=https://login.microsoftonline.com/<TenantId>/v2.0

# JWT 验证
MODELFORGE_JWT_SECRET=<至少32字符的随机密钥>
```

#### 步骤 5：实现 SSO 回调端点

需要在 `Program.cs` 中添加以下端点（已在架构中预留，待人工配置后启用）：

```csharp
// SSO Login redirect
app.MapGet("/api/auth/sso/login", (HttpContext ctx) =>
{
    var redirectUri = $"{ctx.Request.Scheme}://{ctx.Request.Host}/api/auth/callback";
    var authUrl = $"https://login.microsoftonline.com/{tenantId}/oauth2/v2.0/authorize" +
                  $"?client_id={clientId}&response_type=code&redirect_uri={redirectUri}" +
                  $"&scope=openid+profile+User.Read&response_mode=query";
    return Results.Redirect(authUrl);
});

// SSO Callback
app.MapGet("/api/auth/callback", async (HttpContext ctx, IConfiguration cfg) =>
{
    var code = ctx.Request.Query["code"].ToString();
    // 1. 用 code 交换 access_token（POST 到 /oauth2/v2.0/token）
    // 2. 用 access_token 获取用户信息（GET https://graph.microsoft.com/v1.0/me）
    // 3. 在 ModelForge 用户系统中查找或创建用户
    // 4. 签发 JWT 并重定向到前端
});
```

### 方案 B：Okta

1. 登录 Okta Admin Console → **Applications** → **Create App Integration**
2. 选择 **OIDC - OpenID Connect** → **Web Application**
3. 配置：
   - Sign-in redirect URI: `https://modelforge.yourcompany.com/api/auth/callback`
   - Sign-out redirect URI: `https://modelforge.yourcompany.com`
4. 记录 `Client ID` 和 `Client Secret`
5. 配置环境变量：

```bash
SSO__Enabled=true
SSO__Provider=okta
SSO__Okta__Domain=dev-xxxxxx.okta.com
SSO__Okta__ClientId=<Client ID>
SSO__Okta__ClientSecret=<Client Secret>
```

### 验证 SSO

```powershell
# 1. 浏览器访问 https://modelforge.yourcompany.com/api/auth/sso/login
# 2. 应重定向到 Microsoft/Okta 登录页
# 3. 登录成功后应重定向回前端并带有 JWT token
curl -H "Authorization: Bearer <token>" http://localhost:5095/api/auth/me
# 4. 应返回用户身份信息
```

## 2. 云端同步 — OneDrive（P2.17）

### 前置条件

- Microsoft 365 开发者账号（或企业账号）
- OneDrive API 访问权限

### 步骤 1：注册 Azure 应用

1. 登录 [Azure Portal](https://portal.azure.com) → **Microsoft Entra ID** → **应用注册**
2. 如果已完成 SSO 配置，可复用同一个应用；否则新建
3. 进入 **API 权限** → **添加权限** → **Microsoft Graph** → **委托权限**：
   - `Files.ReadWrite` — 读写用户 OneDrive 文件
   - `Files.ReadWrite.All` — 读写所有 OneDrive 文件
   - `offline_access` — 刷新令牌
4. 点击 **代表管理员授予同意**

### 步骤 2：配置环境变量

```bash
ONEDRIVE__Enabled=true
ONEDRIVE__ClientId=<与 SSO 共用或独立 ClientId>
ONEDRIVE__SyncFolder=ModelForge
```

### 步骤 3：实现同步端点（待人工配置后启用）

```csharp
// 上传模板到 OneDrive
app.MapPost("/api/sync/upload", async (HttpContext ctx, IConfiguration cfg) =>
{
    var token = ctx.Request.Headers["Authorization"].ToString().Replace("Bearer ", "");
    var file = ctx.Request.Form.Files[0];

    using var client = new HttpClient();
    client.DefaultRequestHeaders.Authorization =
        new System.Net.Http.Headers.AuthenticationHeaderValue("Bearer", token);

    var uploadUrl = $"https://graph.microsoft.com/v1.0/me/drive/root:/ModelForge/{file.FileName}:/content";
    var response = await client.PutAsync(uploadUrl, new StreamContent(file.OpenReadStream()));

    return Results.Ok(new { success = response.IsSuccessStatusCode });
});

// 从 OneDrive 下载模板
app.MapGet("/api/sync/download", async (HttpContext ctx) =>
{
    var token = ctx.Request.Headers["Authorization"].ToString().Replace("Bearer ", "");
    using var client = new HttpClient();
    client.DefaultRequestHeaders.Authorization =
        new System.Net.Http.Headers.AuthenticationHeaderValue("Bearer", token);

    var listUrl = "https://graph.microsoft.com/v1.0/me/drive/root:/ModelForge:/children";
    var response = await client.GetStringAsync(listUrl);
    return Results.Ok(response);
}).RequireAuthorization();
```

### 测试同步

```powershell
# 上传模板
curl -X POST https://modelforge.yourcompany.com/api/sync/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@mytemplate.json"

# 下载/列表模板
curl https://modelforge.yourcompany.com/api/sync/download \
  -H "Authorization: Bearer <token>"
```

## 补充：Sidecar 启动优化（P3.22）

### 当前状态

键盘钩子已通过 `SidecarOptions.KeyboardHookEnabled` 条件启动，用户可在设置面板切换。

### 进一步优化（如需要）

1. 在真机上测量冷启动耗时：

```powershell
Measure-Command { Start-Process "ModelForge.Sidecar.exe"; Start-Sleep -Milliseconds 500; curl http://localhost:5200/health }
```

2. 如 > 1.5 秒，可延迟初始化 COM 连接池：

```csharp
// Program.cs — 改为首次请求时初始化
builder.Services.AddSingleton<Lazy<OfficeApplicationFactory>>(
    new Lazy<OfficeApplicationFactory>(() => new OfficeApplicationFactory()));
```

3. 将非关键模块标记为延迟加载：

```csharp
// 键盘钩子延迟 3 秒启动
builder.Services.AddHostedService<DeferredKeyboardHook>();
```
