# ModelForge 功能规划

## 1. 项目概述

**项目名称**: ModelForge
**项目类型**: Office 生产力插件套件
**技术架构**: Sidecar (.NET 10 + 原生 COM) + Office JS API 混合架构，通过后端 API 桥接通信
**参考产品**: Macabacus (Excel/PowerPoint/Word 插件)
**目标用户**: 财务专业人士、金融分析师、管理咨询顾问

**当前状态**: 当前仓库以规划文档为主，尚未建立 `src/` 源码骨架。近期重点应从“功能清单罗列”收敛到“可验证 MVP、技术边界、验收标准和实施门禁”。

### 1.1 产品愿景

ModelForge 旨在让投行、私募、风投、FP&A、咨询顾问和企业战略团队在不离开 Office 的前提下，完成从财务模型搭建、数据联动、演示材料生成、长文档协作到品牌合规检查的完整工作流。

### 1.2 目标用户画像

| 用户角色 | 典型组织 | 关键诉求 | 高频能力 |
| -------- | -------- | -------- | -------- |
| 金融分析师 / Analyst | 投行、PE、VC、FP&A | 快速搭建和审计财务模型 | 快捷键、Power Tools、Model Check、Visualizations |
| 项目经理 / Associate / VP | 投行、咨询、战略部门 | 统一模型与汇报材料，减少返工 | Excel-PPT 链接、Deck Check、模板库 |
| 咨询顾问 | 咨询公司、企业战略 | 快速制作品牌一致的演示文稿 | MasterShapes、Dynamic Agendas、Logo Library |
| 文档负责人 | 法务、投后、尽调团队 | 结构化生成长文档并维护引用 | Doc Builder、目录、书签、Link to Excel |
| 企业管理员 | IT、运营、品牌管理 | 统一权限、模板、术语和审计 | Admin Console、Corporate Dictionary、Dashboard |
| 合规 / 安全负责人 | 金融机构、上市公司 | 控制敏感数据和外发风险 | Prepare to Share、审计日志、私有化 AI、策略下发 |

### 1.3 核心工作流

1. **建模工作流**: 建立预测表 → 快捷键格式化 → 公式填充 → 视觉审计 → Model Check → Prepare to Share。
2. **投委会材料工作流**: Excel 图表/表格链接到 PowerPoint → 套用品牌模板 → 自动目录/页码 → Deck Check → 输出 PDF。
3. **尽调文档工作流**: 从结构化问卷生成 Word 初稿 → 插入 Excel 表格/图表链接 → 自动目录与交叉引用 → 安全发布。
4. **企业治理工作流**: 管理员配置品牌库、术语库和策略 → 用户侧自动拉取 → 关键操作上报 → Dashboard 统计效率与风险。

### 1.5 MVP 范围建议

**纳入 MVP（建议版本 0.2）**:

- Excel Sidecar 基础 Ribbon 与命令框架。
- 20 个以内高频快捷键，支持配置文件导入/导出和冲突提示。
- Power Tools 基础版：快速横向/纵向填充、IFERROR 封装、统计公式插入。
- Visualizations 基础版：识别硬编码、公式、外部链接并标色。
- Model Check 基础版：错误值、外部链接、循环引用、硬编码扫描。
- Workbook Optimization 与 Prepare to Share 基础版。
- Excel → PowerPoint 链接原型：Range / Chart 插入与手动刷新。
- 后端健康检查、配置读写、链接元数据存储、审计事件上报。
- Web 管理端最小可用界面：配置查看、字典维护、事件列表。

**暂不纳入 MVP**:

- 完整 SSO、复杂 RBAC、多租户计费。
- AIWA 真实大模型生产调用。
- 完整 PowerPoint / Word 插件能力。
- 100+ 快捷键全量覆盖。
- Brandfetch 等第三方 Logo 数据服务生产集成。

## 2. 技术架构

### 2.1 架构选型

| 能力需求                                        | Web Add-in  | Sidecar (.NET 10 + 原生 COM) | 结论                     |
| ----------------------------------------------- | ----------- | ---------------------------- | ------------------------ |
| Keyboard Shortcuts (快捷键)                     | 部分支持   | ✅ Win32 全局钩子             | **Sidecar + Office.js 双轨** |
| Link Excel to PowerPoint/Word (深度COM引用绑定) | ❌ 能力有限 | ✅ 原生 COM 完全支持     | Sidecar 实现             |
| 颜色板、共享库检索                              | ✅ 轻量更新 | ❌ 需重新安装                 | Web更灵活                |
| Deck Check 报告生成界面                         | ✅ 热更新   | ❌ 需重新安装                 | Web更优                  |
| Ribbon 菜单融合                                 | ✅ 支持     | N/A (通过 manifest 驱动)      | 两者皆可                 |

**重要澄清**：Sidecar 与 Web Add-in 运行在不同进程，禁止直接通信。两者的功能协调必须通过 localhost REST API 和后端 API 桥接实现。

### 2.2 功能分工

#### Sidecar 负责 (.NET 10 Minimal API + 原生 COM)

- 快捷键系统 (Win32 WH_KEYBOARD_LL 全局钩子，100+ 可自定义)
- 跨应用数据联动 (Excel ↔ PowerPoint ↔ Word，原生 COM)
- Power Tools (快速填充、错误封装、公式简化、统计摘要)
- 公式追踪 & Model Check (硬编码/外部链接/循环引用扫描)
- 文件优化 & Prepare to Share (公式转数值、批注清除)
- Visualizations (三色视觉审计：硬编码/公式/外部链接)
- 高级图表增强 (Chart Add-ons, 快速格式化)
- 形状批量操作 (对齐、分布、统一尺寸)
- PPT/Word 底层交互 (动态目录、页码、形状库、合规检查)

#### Web Add-in 负责 (灵活更新无需安装包)

- Admin Console (企业后台：用户/角色/SSO/审计日志)
- Shared Libraries & Corporate Dictionary (品牌库、术语库管理)
- Dashboard 统计 (使用热力图、效率趋势)
- Omnibar 速查栏 (全局命令搜索)
- AIWA 前端 UI (对话界面、结果展示)
- 配置管理 (企业策略下发、快捷键预设同步)

## 3. 核心功能模块

### 3.1 Excel Sidecar 服务

#### 3.1.1 财务建模核心效率工具 (P0)

- **Power Tools（建模自动化套件）**:
    - 快速横向/纵向填充：批量填充公式与格式，构建预测行/列结构。
    - 错误封装：一键用 IFERROR 包装易错公式，减少模型错误传播。
    - 公式简化：识别嵌套冗余公式并给出简化建议 (后端辅助)。
    - 描述性统计：快速插入选定区域的 MIN/MAX/AVERAGE/COUNT 等公式。
- **快捷键系统**: 100+ 可完全自定义的快捷键，覆盖格式化、跳转、建模全流程。
- **Visualizations（视觉审计）**: 动态识别硬编码（蓝色）、公式（黑色）、外部链接（绿色）并着色，直观把控模型风险。
- **Prepopulated Tables（分析模版库）**: 从中心库一键插入预填 DCF 表、Black‑Scholes 定价表等常用金融分析模板。

#### 3.1.2 公式审核与模型检查 (P0)

- **公式追踪**：跨工作表/跨工作簿一键追溯所有 Precedents 和 Dependents。
- **Model Check 引擎**：全面审计硬编码、断裂外部链接、错误值（#REF!、#N/A、#VALUE!）和循环引用，提供一键修复或汇总报告。
- **Formula Flow**：窗格并列对比多个单元格的复杂逻辑链，精准 Debug。
- **审计标色**: 在模型审计过程中视觉标记非常规公式的校验状态。

#### 3.1.3 跨应用数据联动 (P0 — 护城河功能)

- **核心联动**: Excel ↔ PowerPoint ↔ Word 深度绑定（Range、Chart、PivotTable 等）。
- **同步刷新**: 点击刷新按钮即可批量更新所有 Office 文件中的联动内容，实时检测外部依赖断链并提示安全修复。
- **元数据管理**: Web Add-in 负责联动配置 (数据源、刷新策略)，实际刷新由 Sidecar 执行。

#### 3.1.4 高级图表与 Chart 工具 (P1)

- **动态图扩展能力**: 快速在已有图表上添加新数据序列/自定义误差线/交叉点；批量对齐图表轴线与配色品牌规范。
- **图表样式库**: 一键套用品牌颜色，快速切换图表风格。
- **快速图表**: 选定数据区域后一键插入最合理图表类型。

#### 3.1.5 文件优化与安全发布 (P0)

- **Workbook Optimization**（文件深度优化）: 自动缩减文件体积，清除未使用样式、过界数据残影、无效名称等。
- **Prepare to Share**（安全发布）: 盲化公式、移除全部批注、敏感字符屏蔽，用于向非编辑权限客户发送模型。

#### 3.1.6 工作簿管理增强 (P1)

- 批量取消隐藏/重命名/移动工作表。
- Names Manager 增强：筛选、批量转换无效命名区域，清理外部链接。

#### 3.1.7 格式工具 (P1)

- 财务专用格式「会计下划线、千分位、百分比」一键应用。
- 单元格样式循环切换，格式刷增强。

#### 3.1.8 形状批量操作 (P2)

- 对齐、统一尺寸、分布排列、旋转等。

### 3.2 PowerPoint Sidecar 服务

#### 3.2.1 幻灯片自动编排与合规 (P0-P1)

- **Dynamic Agendas（动态目录）**: 与原生 Section 双向同步，自动生成并维护动态目录/节标题，增删节时自动更新。
- **Pagination（高级页码）**: 对开双页、白页标注、复杂幻灯片编号、双/单面打印控制。
- **New Presentations**: 基于品牌模板矩阵一键创建合规演示文稿初稿。

#### 3.2.2 MasterShapes, TurboShapes 与 Meta Shapes (P1)

- **MasterShapes**：基于角色的图形模板库，支持品牌布局约束。
- **TurboShapes 多状态控件**：呈现项目进度、评分、多选项（如开关）等数据可视化。
- **Meta Shapes**：支持为形状附加动态元标签 (Key-Value)，辅助按 Deal 类型筛选并快速插入标准内容。
- **Logo Library**：借助 Brandfetch 等第三方品牌 Logo 数据库快速插入 logo，也支持企业定制 Logo 库上传。
- **Tombstones（交易清单幻灯片）** : 从后台选择预制 “Creds 页面” 快速填充客户 Logo、分类、交易细节。

#### 3.2.3 Deck Check 与品牌证明 (P0)

- **Presentation Proofing**：全文扫描品牌字体缺失、Logo 偏移、违禁术语（支持正则匹配）。
- **Deck Check 报告生成和 Corporate Dictionary 联动**: 基于企业中心术语字典检查语言合规，输出 PDF 审核报告。

#### 3.2.4 形状对齐与布局工具 (P1)

- 对齐/均匀分布/旋转/批量尺寸增减。

#### 3.2.5 图表集成 (P1)

- 基于 Excel 联动数据的高级动态图表式支持（公式驱动的动画与刷新）。

#### 3.2.6 样式与母版管理 (P1)

- **Styles 主题库**（字体、配色、背景快速套版）。
- **Slide Master 快捷编辑**。

#### 3.2.7 Reformat View（格式查找与替换）(P2)

- 全演示文稿限定格式条件进行批量查找与替换字体/颜色/填充。

### 3.3 Word Sidecar 服务

#### 3.3.1 文档导航与构建 (P1)

- **导航窗格**: 标题导航、页面缩略图。
- **书签与目录工具**: 自动生成/更新目录，批量管理书签。
- **Doc Builder（文档构建器）**: 基于结构化问卷表自动生成投资意向书、尽调清单等长文档初稿。

#### 3.3.2 格式与表格工具 (P1)

- **样式应用**: 快速应用预设样式，格式刷增强。
- **表格快速编辑**: 插入/删除行列，预设表格样式。
- **脚注尾注与交叉引用**: 批量管理与更新。

#### 3.3.3 跨应用链接 (P0)

- **Link to Excel**: OLE 嵌入 Excel 表格/图表，数据源更新后一键刷新 Word 文档内容。

#### 3.3.4 文档保护 (P2)

- 文档保护、密码设置、编辑限制。

## 4. Web Add-in 功能模块

### 4.1 Admin Console (企业后台)

- **用户管理**: 对接 SSO (SAML/OIDC)，角色分配 (普通用户/审计员/管理员)。
- **权限配置**: 功能权限、数据权限、企业策略下发（如强制快捷键配置）。
- **审计日志**: 记录关键操作，支持导出。
- **系统设置**: 全局插件配置、更新策略。

### 4.2 Shared Libraries & Corporate Dictionary

- **品牌模板管理**: Logo、配色方案、字体库的集中上传与版本控制。
- **合同条款库**: 常用条款模板、条款库分类。
- **Corporate Dictionary（企业术语库）**: 支持正则匹配、强制替换规则，供 Deck Check 和 AIWA 调用。

### 4.3 Dashboard 统计

- **使用频率统计**: 热力图展示各功能使用次数。
- **功能使用报表**: 趋势分析、功能排行榜。
- **用户行为分析**: 效率增益估算，部门活跃度对比。

### 4.4 Omnibar 速查栏

- **快速搜索框**: 全局搜索 Office 原生命令 + ModelForge 扩展命令，根据当前选中对象智能展示上下文相关命令。
- **快捷命令**: 常用操作快捷入口。
- **历史记录**: 最近使用的文件、功能记录。

### 4.5 AIWA 前端 UI

- **AI 对话界面**: 自然语言交互 (Summarize, Elaborate, Rephrase, Proofread, Translate)。
- **结果展示组件**: 图表、表格、图文混排。
- **后端调用**: 通过企业配置的大模型 API (支持 Azure OpenAI / 私有化 Llama3) 执行，自动注入 Corporate Dictionary 规则。

### 4.6 配置与设置管理

- **用户偏好设置**: 个人快捷键、默认模板选择。
- **工作区配置导入/导出**。
- **云端同步** (可选，通过 OneDrive/SharePoint)。

### 5.3 设置管理

- 工作区配置导出/导入

## 6. 企业级与安全功能

- **SSO**: 支持企业 SAML 2.0 / OIDC 登录。
- **数据隐私**: 管理员可关闭遥测和错误日志上传；支持私有化 AI 部署。
- **安全审查**: 提供 SOC2 报告、渗透测试配合。
- **用户组与集中管理**: 按部门批量控权，版本回滚 (Downgrade Rights)。

| ---- | ---- |
| 性能 | Sidecar 冷启动开销 ≤ 1.5 秒；大范围扫描需显示进度并允许取消；批量操作应合并 COM 调用。 |
| 稳定性 | COM 对象必须显式释放；跨应用链接失败时提供可恢复状态，不得破坏原文件。 |
| 兼容性 | 覆盖 Office 2016/2019/365（Windows）；明确标注不支持或降级能力。 |
| 安全 | 默认最小权限；敏感内容不默认上传；AI 功能支持关闭、BYOK 和私有化部署。 |
| 隐私 | 遥测默认只采集功能事件与匿名上下文，不采集文档正文；管理员可关闭。 |
| 可观测性 | Sidecar、Web、后端统一 TraceId；本地日志可导出用于支持。 |
| 可维护性 | 命令定义、快捷键、策略、字典、模板应配置化，不硬编码在 UI 中。 |
| 可访问性 | Web UI 遵循 Fluent UI 可访问性实践，支持键盘导航。 |
| 国际化 | 初期中文界面优先，命令与文档结构预留英文资源文件。 |

## 10. 数据安全与权限边界

1. **文档内容本地优先**：Excel/PowerPoint/Word 文件正文默认只在本地处理。
2. **元数据可上传**：链接关系、命令事件、错误类型、字典命中摘要可上传，但需脱敏。
3. **AI 调用显式授权**：任何文档正文进入 AI 服务前必须有用户动作或管理员策略授权。
4. **Prepare to Share 不覆盖源文件**：默认生成副本，所有破坏性操作需要二次确认。
5. **审计不可伪造**：关键操作应由后端记录用户、时间、租户、命令、目标文件摘要与结果状态。

## 11. 依赖、约束与待决问题

| 事项 | 影响 | 建议决策时点 |
| ---- | ---- | ------------ |
| 首个商业化目标是个人专业版还是企业版 | 授权、部署、Admin Console 优先级 | 阶段一结束前 |
| 数据库首选 PostgreSQL 还是 SQL Server | 后端部署、企业兼容 | 后端骨架创建前 |
| Sidecar 安装方式优先 MSI/WiX Windows Service | 企业分发和升级 | 阶段一中期 |
| 是否需要多租户 SaaS | 数据模型、权限、安全 | 阶段三前 |
| AIWA 是否进入 1.0 | 安全、成本、研发排期 | Beta 前 |
| 是否引入第三方 Logo / 数据 API | 合规与成本 | PowerPoint 模块启动前 |

## 12. 近期规划结论

1. **先做 Excel Sidecar MVP**，用可演示的建模效率和模型检查证明核心价值。
2. **后端桥接不可省略**，即便 MVP 也至少需要健康检查、配置、链接元数据和审计事件。
3. **Web Add-in 先做治理最小闭环**，不要过早投入复杂 Dashboard 和 AIWA。
4. **PowerPoint 与 Word 依赖 Excel 链接能力成熟后推进**，避免跨应用链路重复返工。
5. **所有破坏性 Office 操作都必须有备份、预览或撤销策略**，这是金融场景可信度底线。
