# ModelForge 功能规划

## 1. 项目概述

**项目名称**: ModelForge
**项目类型**: Office 生产力插件套件
**技术架构**: VSTO + Office JS API 混合架构 (Hybrid 模式)
**参考产品**: Macabacus (Excel/PowerPoint/Word 插件)
**目标用户**: 财务专业人士、金融分析师、管理咨询顾问

## 2. 技术架构

### 2.1 架构选型

| 能力需求                                        | Web Add-in  | VSTO          | 结论                     |
| ----------------------------------------------- | ----------- | ------------- | ------------------------ |
| Keyboard Shortcuts (快捷键)                     | ❌ 不支持   | ✅ 完全支持   | **P0级刚需，必须用VSTO** |
| Link Excel to PowerPoint/Word (深度COM引用绑定) | ❌ 能力有限 | ✅ 完全支持   | 需要VSTO实现             |
| 颜色板、共享库检索                              | ✅ 轻量更新 | ❌ 需重新安装 | Web更灵活                |
| Deck Check 报告生成界面                         | ✅ 热更新   | ❌ 需重新安装 | Web更优                  |
| Ribbon 菜单融合                                 | ✅ 支持     | ✅ 支持       | 两者皆可                 |

### 2.2 功能分工

#### VSTO 负责 (压力级速度建模)

- 快捷键系统
- 跨应用数据联动 (Excel ↔ PowerPoint ↔ Word)
- 公式追踪
- 文件优化
- 模型检查
- 形状批量操作

#### Web Add-in 负责 (灵活更新无需安装包)

- 合同与品牌库运维后台
- Dashboard 统计
- Omnibar 速查栏
- AIWA 前端 UI
- 管理员后台配置台

## 3. 核心功能模块

### 3.1 Excel VSTO 插件 (modelforge.excel)

#### 3.1.1 财务建模工具 (VSTO - P0)

- **快捷键系统**: 自定义财务建模常用快捷键绑定 (P0级刚需)
- **跨应用数据联动**: Excel ↔ PowerPoint ↔ Word 深度链接
- **公式审核**: 公式追踪、引用关系可视化
- **模型检查**: 工作簿健康检查、自动修复

#### 3.1.2 格式工具 (VSTO)

- **数字格式快速应用**: 会计格式、百分比格式等一键应用
- **格式刷增强**: 批量格式刷、多格式选择性粘贴
- **条件格式工具**: 财务专用条件格式规则

#### 3.1.3 工作表管理 (VSTO)

- **工作表批量操作**: 批量创建/复制/移动/重命名
- **工作表导航**: 快速跳转、多窗口同步滚动
- **名称管理器增强**: 名称批量创建、命名规则自动化

#### 3.1.4 文件操作 (VSTO)

- **工作簿比较**: 两个工作簿差异对比
- **链接管理**: 外部链接查看、更新、断链修复
- **文件优化**: 压缩图片、清除冗余数据

#### 3.1.5 形状批量操作 (VSTO)

- **形状批量选择**: 按类型/大小/位置筛选
- **形状格式统一**: 批量设置填充/线条/效果
- **形状对齐分布**: 精确对齐、均匀分布

### 3.2 PowerPoint VSTO 插件 (modelforge.powerpoint)

#### 3.2.1 幻灯片管理 (VSTO)

- **幻灯片导航**: 缩略图导航、幻灯片排序
- **批量操作**: 批量复制/删除/重排幻灯片
- **节管理**: 将幻灯片分组为多个节

#### 3.2.2 形状和对象 (VSTO)

- **形状工具集**: 常用形状快速插入
- **对齐工具**: 精确对齐多个对象
- **分布工具**: 均匀分布对象
- **组合管理**: 快速组合/取消组合对象

#### 3.2.3 设计工具 (VSTO)

- **布局库**: 预设幻灯片布局
- **主题应用**: 快速应用主题颜色、字体
- **母版编辑**: 幻灯片母版快速编辑

#### 3.2.4 图表集成 (VSTO)

- **图表插入**: 从 Excel 数据快速创建图表
- **图表样式**: 预设图表样式
- **图表动画**: 快速添加图表动画效果

### 3.3 Word VSTO 插件 (modelforge.word)

#### 3.3.1 文档导航 (VSTO)

- **导航窗格**: 标题导航、页面缩略图
- **书签管理**: 快速插入/跳转到书签
- **目录工具**: 自动生成/更新目录

#### 3.3.2 格式工具 (VSTO)

- **样式应用**: 快速应用预设样式
- **格式刷增强**: 批量格式应用
- **段落格式**: 缩进、行距、对齐快速设置

#### 3.3.3 表格工具 (VSTO)

- **表格创建**: 快速插入标准表格
- **表格编辑**: 添加/删除行列
- **表格样式**: 预设表格样式

#### 3.3.4 引用工具 (VSTO)

- **脚注尾注**: 快速插入脚注尾注
- **交叉引用**: 创建交叉引用
- **题注**: 自动编号图表、表格题注

#### 3.3.5 文档保护 (VSTO)

- **文档保护**: 设置编辑限制
- **密码管理**: 文档密码设置

## 4. Web Add-in 功能模块

### 4.1 合同与品牌库运维后台

- **品牌模板管理**: Logo、配色方案、字体库
- **合同条款库**: 常用条款模板、条款库分类
- **配色方案管理**: 预设调色板、自定义配色

### 4.2 Dashboard 统计

- **使用频率统计**: 各功能使用次数、趋势分析
- **功能使用报表**: 热力图、使用排行榜
- **用户行为分析**: 操作习惯分析、效率指标

### 4.3 Omnibar 速查栏

- **快速搜索框**: 全局搜索、命令搜索
- **快捷命令**: 常用操作快捷入口
- **历史记录**: 最近使用的文件、功能记录

### 4.4 AIWA 前端 UI

- **AI 对话界面**: 自然语言交互
- **结果展示组件**: 图表、表格、图文混排
- **大模型调用接口**: 保留后端大模型独立性

### 4.5 管理员后台配置台

- **用户管理**: 用户列表、角色分配
- **权限配置**: 功能权限、数据权限
- **系统设置**: 插件配置、默认参数

## 5. 通用功能

### 5.1 快捷键系统 (VSTO)

- 全局快捷键注册
- 自定义快捷键映射
- 快捷键冲突检测
- 快捷键配置导入/导出

- 功能区标签页
- VSTO 命令与 Web 命令统一调度

- 工作区配置导出/导入
- 云端同步 (可选)

## 6. 技术架构建议

### 6.1 项目结构

```
ModelForge/
├── src/
│   ├── vsto/                        # VSTO 插件项目
│   │   ├── ModelForge.AddIn/        # Excel VSTO
│   │   ├── ModelForge.PowerPoint/   # PowerPoint VSTO
│   │   └── ModelForge.Word/         # Word VSTO
│   │
│   ├── web/                         # Web Add-in 项目
│   │   ├── src/
│   │   │   ├── components/          # React 组件
│   │   │   ├── views/              # 页面视图
│   │   │   └── services/            # API 服务
│   │   └── package.json
│   │
│   └── shared/                      # 共享代码
│       ├── constants/               # 常量定义
│       ├── types/                  # 类型声明
│       └── utils/                  # 工具函数
│
├── manifest/                        # Add-in Manifest 配置
└── docs/                            # 文档
```

### 6.2 技术栈

| 层级              | 技术选型                           | 说明                  |
| ----------------- | ---------------------------------- | --------------------- |
| **VSTO 运行时**   | .NET 8                             | 桌面插件宿主          |
| **Office JS API** | Office.js + Office Add-in Manifest | Web 插件              |
| **通信桥接**      | SharedRuntime                      | VSTO + Web 共享运行时 |
| **前端框架**      | React 18 / TypeScript              | Web Add-in UI         |
| **UI 组件库**     | Fluent UI React                    | Microsoft 设计系统    |
| **构建工具**      | Vite                               | Web Add-in 打包       |
| **后端 API**      | RESTful / GraphQL                  | Web Add-in 数据接口   |
