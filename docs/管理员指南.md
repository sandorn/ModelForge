# ModelForge 管理员指南

## 部署架构

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ Office Add-in │────▶│ Sidecar       │────▶│ Backend API  │
│ (WebView2)    │     │ (Win Service) │     │ (Win Service)│
│ :5173        │     │ :5200         │     │ :5095        │
└─────────────┘     └──────────────┘     └─────────────┘
                                                    │
                                             ┌──────▼──────┐
                                             │ PostgreSQL   │
                                             │ / SQL Server │
                                             └─────────────┘
```

## 生产部署

### 1. 构建 MSI

```powershell
# 安装 WiX v5
dotnet tool install --global wix

# 构建所有组件
.\scripts\build-installer.ps1 -Configuration Release

# 构建 MSI
dotnet build installer\ModelForge.Installer\ModelForge.Installer.wixproj -c Release
```

### 2. 安装

```powershell
# 静默安装（管理员权限）
msiexec /i ModelForge-0.1.0.msi /quiet

# 验证服务已启动
sc query ModelForge.Sidecar
sc query ModelForge.Backend
curl http://localhost:5200/health
curl http://localhost:5095/health
```

### 3. 配置

编辑 `C:\Program Files\ModelForge\Sidecar\appsettings.json`：

```json
{
  "Sidecar": {
    "BackendBaseUrl": "http://localhost:5095",
    "SidecarPort": 5200,
    "KeyboardHookEnabled": true
  }
}
```

### 4. 数据库

后端默认使用内存存储（开发模式）。生产环境配置 PostgreSQL：

```
MODELFORGE_DB_CONNECTION=Host=db-server;Database=ModelForge;Username=modelforge
```

### 5. Office 清单分发

企业部署环境可集中管理 Office Add-in 清单：

```
# 组策略路径
Computer Configuration → Administrative Templates → Microsoft Office → Trusted Add-in Catalogs
```

或手动复制到每台机器：

```powershell
Copy-Item "manifest\modelForge.web.xml" "$env:LOCALAPPDATA\Microsoft\Office\WEF\"
```

## 系统要求

| 组件 | 要求 |
|------|------|
| Windows | Windows 10/11, Windows Server 2019+ |
| Office | Office 2016/2019/365 桌面版 |
| .NET | .NET 10 Runtime (self-contained 部署无需单独安装) |
| 数据库 | PostgreSQL 14+ 或 SQL Server 2019+ |

## 服务管理

```powershell
# 重启服务
Restart-Service ModelForge.Sidecar
Restart-Service ModelForge.Backend

# 查看日志
Get-EventLog -LogName Application -Source ModelForge.Sidecar -Newest 20

# 停止/卸载
sc stop ModelForge.Sidecar
sc stop ModelForge.Backend
msiexec /x ModelForge-0.1.0.msi
```

## 安全注意事项

- Sidecar 和 Backend 仅监听 `localhost`，不对外暴露端口
- 生产环境建议配置 HTTPS 证书
- 键盘钩子可能触发杀毒软件告警 — 将 `ModelForge.Sidecar.exe` 加入白名单
- `Prepare to Share` 功能从不修改原始工作簿 — 始终生成副本
