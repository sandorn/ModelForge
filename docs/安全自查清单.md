# ModelForge 安全自查清单

> 适用范围：`0.1.1-stage1` 内测/试点发布。正式生产发布前，以下条目需由工程、IT 管理员和业务负责人共同确认。

## 1. 凭据与认证

- [ ] 修改所有默认账号密码；`admin/admin123`、`analyst/analyst123`、`auditor/auditor123` 仅允许本地开发使用。
- [ ] 生产环境禁用或替换内存用户存储；接入企业 SSO/身份目录前，不对外开放管理端口。
- [ ] 配置强随机 `Jwt__SecretKey`，禁止使用 `ChangeMe`、示例值或提交到仓库的密钥。
- [ ] 管理员账号启用 MFA；最小化 Global Admin / Application Admin 使用范围。

## 2. 本机服务边界

- [ ] Sidecar 仅监听 `localhost:5200`，Backend 仅监听预期内网/本机地址。
- [ ] 防火墙不向公网暴露 `5200`、`5095` 等本地服务端口。
- [ ] 试点/生产启用 `Sidecar:LocalApiToken`，并确认 Web Add-in 请求携带 `X-ModelForge-Sidecar-Token`；本地开发空值仅限开发机。
- [ ] Sidecar `/api/execute` 保持 `commandId` 非空校验和 `host` 白名单校验。
- [ ] 高风险 Office 操作保留用户确认、错误提示或安全副本策略。

## 3. 数据与日志

- [ ] 工作簿内容默认不上传到公有服务；AIWA 生产接入前必须明确数据出境策略。
- [ ] 审计日志导出 CSV 前确认权限，仅 Admin 可导出。
- [x] 审计日志保留策略基础版已配置；发布前需确认 `AuditRetentionDays` 符合企业留存要求，并先 dry-run 再执行清理。
- [ ] 日志不得包含完整工作簿内容、JWT、密码、API Key 或客户敏感文本。
- [ ] SQLite/PostgreSQL 数据库文件和备份纳入企业数据保留与加密策略。
- [ ] 确认 `TelemetryEnabled` 默认关闭；如需开启使用统计，完成内部告知、数据范围说明和审批。

## 4. Office 与 COM

- [ ] 覆盖目标 Office 版本（Office 2016/2019/2024/Microsoft 365，32/64 位策略需明确）。
- [ ] 验证 Excel/PowerPoint/Word 与 Sidecar 运行在同一用户权限上下文。
- [ ] 确认安全软件不会拦截全局键盘钩子或 COM 自动化；必要时走企业白名单流程。
- [ ] 发布前完成真实 Ribbon 侧载点击回归，而不只依赖静态 manifest 测试。

## 5. Web Add-in 与前端

- [ ] 生产 Web Add-in 资源通过 HTTPS 托管，并使用企业可信证书。
- [ ] Manifest `SourceLocation`、`FunctionFile` 和图标 URL 指向生产域名或安装目录。
- [ ] CORS 白名单只包含企业批准的 Web Add-in 域名。
- [ ] 前端依赖执行 `npm audit --omit=dev --registry=https://registry.npmjs.org`，无未评估高危漏洞。

## 6. 安装包与部署

- [x] `ModelForge.msi` 使用管理员 PowerShell 完成安装/卸载回归。
- [x] MSI 回归命令使用 `.\scripts\test-msi-admin.ps1` 或 `Resolve-Path` 解析后的绝对 MSI 路径；不得直接把 `.\ModelForge.msi` 传给 `msiexec` 作为发布验收证据。
- [x] 验证 Windows Service：`ModelForge.Sidecar`、`ModelForge.Backend` 可启动、停止、重启。
- [x] 安装后验证 Backend `/health`、Sidecar `/health`。
- [x] 卸载后确认服务已移除。

## 7. 发布门禁

- [ ] `dotnet test ModelForge.sln -c Release --filter "FullyQualifiedName!~ComPpt&FullyQualifiedName!~ComWord&FullyQualifiedName!~ComInterop&FullyQualifiedName!~ComPowerTools"` 通过。
- [ ] `npm test -- --run` 与 `npm run build` 通过。
- [ ] Office 2024 用户式 E2E 脚本通过并归档产物。
- [ ] 已知限制写入发布说明：MSI 管理员安装、Ribbon 真实点击、SSO/RBAC、AIWA 生产接入等。
