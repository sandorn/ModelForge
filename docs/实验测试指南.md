# ModelForge 0.2.0 本地实验测试指南

> 无需 SSO · 无需 OneDrive · 无需视频 · 纯本地即可跑通全部 146 个命令

## 硬件前提

| 要求 | 说明 |
|------|------|
| Windows 10/11 | 64 位 |
| .NET 10 SDK | `dotnet --version` ≥ 10.0 |
| Node.js 20+ | `node --version` ≥ 20 |
| Microsoft Office 桌面版 | Excel + PowerPoint + Word（2016/2019/2021/365 均可） |

## 一、启动三步走

### 1. 启动 Backend（端口 5095）

```powershell
cd d:\CODES\model-forge
dotnet run --project src/backend/ModelForge.Backend
```

看到 `Now listening on: http://localhost:5095` 即成功。

验证：
```powershell
curl http://localhost:5095/health
# → {"data":{"status":"Healthy","service":"ModelForge.Backend",...}}
```

### 2. 启动 Sidecar（端口 5200）

开一个新终端：
```powershell
cd d:\CODES\model-forge
dotnet run --project src/sidecar/ModelForge.Sidecar
```

看到 `Now listening on: http://localhost:5200` 即成功。

验证：
```powershell
curl http://localhost:5200/health
# → Sidecar 会尝试连接运行中的 Office
```

### 3. 启动 Web Add-in（端口 5173）

开第三个终端：
```powershell
cd d:\CODES\model-forge\src\web
npm install        # 仅首次
npm run dev        # 启动 Vite 开发服务器
```

浏览器访问 `https://localhost:5173`（接受自签名证书警告）。

### Excel 命令速测

  -H "Content-Type: application/json" \

## 五、Backend API 实验（无需 Office）

```powershell
# 健康检查
curl http://localhost:5095/health

# 版本信息
curl http://localhost:5095/api/version

# 命令目录
curl http://localhost:5095/api/commands

# 登录获取 Token
curl -X POST http://localhost:5095/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 使用 Token 访问 Admin API（替换 <token>）
$token = "<token from login response>"

# Dashboard 统计
curl http://localhost:5095/api/dashboard/summary

# 用户列表
curl http://localhost:5095/api/admin/users \
  -H "Authorization: Bearer $token"

# 角色列表
curl http://localhost:5095/api/admin/roles \
  -H "Authorization: Bearer $token"

# 审计事件
curl http://localhost:5095/api/admin/audit-events?count=10 \
  -H "Authorization: Bearer $token"

# 诊断信息
curl http://localhost:5095/api/admin/diagnostics \
  -H "Authorization: Bearer $token"

# 企业策略
curl http://localhost:5095/api/policy

# 品牌模板
curl http://localhost:5095/api/brand

# 用户组
curl http://localhost:5095/api/admin/groups \
  -H "Authorization: Bearer $token"

# 版本历史
curl http://localhost:5095/api/versions

# AIWA 配置
curl http://localhost:5095/api/aiwa/config

# AIWA Chat (Mock 模式)
curl -X POST http://localhost:5095/api/aiwa/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"总结一下财务建模的关键步骤","mode":"summarize"}'

# 术语字典
curl http://localhost:5095/api/dictionary/

# 术语检查
curl -X POST http://localhost:5095/api/dictionary/check \
  -H "Content-Type: application/json" \
  -d '{"text":"本文件包含机密信息和草案版本"}'
```
