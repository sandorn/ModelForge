# ModelForge 用户指南

## 快速开始

### 1. 启动服务

```powershell
# 启动后端 API (端口 5095)
dotnet run --project src\backend\ModelForge.Backend

# 启动 Sidecar (端口 5200)
dotnet run --project src\sidecar\ModelForge.Sidecar

# 启动 Web Add-in 开发服务器 (端口 5173)
cd src\web && npm run dev
```

### 2. 在 Excel 中侧载

1. 将 `manifest\modelForge.web.xml` 复制到 Office 受信任目录
2. 打开 Excel → 插入 → 我的加载项 → 共享文件夹 → 选择 `modelForge.web.xml`
3. ModelForge 标签页出现在 Ribbon 上

### 3. 使用功能

#### Ribbon 按钮

点击 ModelForge 标签下的 Ribbon 按钮直接执行命令：

| 组 | 按钮 | 快捷键 |
|----|------|--------|
| Power Tools | 向右填充 | `Ctrl+Alt+R` |
| | 向下填充 | `Ctrl+Alt+D` |
| | IFERROR | `Ctrl+Alt+E` |
| | 统计摘要 | `Ctrl+Alt+S` |
| | 财务格式 | `Ctrl+Alt+N` |
| | 正负号切换 | `Ctrl+Alt+G` |
| | DCF 模板 | `Ctrl+Alt+1` |
| 模型审计 | 标记输入 | `Ctrl+Alt+I` |
| | 标记公式 | `Ctrl+Alt+F` |
| | 标记外链 | `Ctrl+Alt+L` |
| | 清除标色 | `Ctrl+Alt+C` |
| | Model Check | `Ctrl+Alt+M` |
| | 追踪前驱 | `Ctrl+Alt+P` |
| | 追踪依赖 | `Ctrl+Alt+T` |
| | 清除追踪 | `Ctrl+Alt+X` |
| 跨应用联动 | 链接至 PPT | `Ctrl+Alt+K` |
| | 刷新链接 | `Ctrl+Alt+U` |
| 工作簿工具 | 优化工作簿 | `Ctrl+Alt+O` |
| | 安全外发 | `Ctrl+Alt+H` |

#### 任务窗格

点击 Ribbon "打开任务窗格" 按钮打开侧边栏：

- **总览**: 查看 Backend 和 Sidecar 连接状态
- **命令**: 按分组浏览和执行所有命令
- **Excel**: 查看当前工作簿、工作表、选中区域信息
- **审计**: 查看审计相关命令列表
- **AIWA**: AI 写作助手对话界面
- **管理**: 用户管理和审计日志(需权限)

#### Omnibar 搜索

点击右下角搜索按钮或按 `Ctrl+Shift+P` 打开命令面板，输入关键词即时搜索所有命令。

### 4. 快捷键自定义

通过 Sidecar API 管理快捷键：

```powershell
# 查看所有快捷键
curl http://localhost:5200/api/shortcuts

# 执行命令
curl -X POST http://localhost:5200/api/execute -H "Content-Type: application/json" -d '{"commandId":"excel.fill-right","host":"excel"}'
```

### 5. 常见操作

**安全外发工作簿**:
1. 打开 Excel 工作簿
2. 点击 "安全外发" 按钮
3. 确认输出路径 → 生成 `*_SafeCopy.xlsx` 副本

**Model Check**:
1. 打开需要审计的工作簿
2. 点击 "Model Check" 按钮
3. 在任务窗格的审计面板查看结果

**Excel → PowerPoint 链接**:
1. 在 Excel 选中要链接的区域
2. 启动 PowerPoint 并打开目标演示文稿
3. 点击 "链接至 PPT" 按钮
